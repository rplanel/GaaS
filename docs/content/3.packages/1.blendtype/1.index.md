## What is Blendtype?

Blendtype is the TypeScript client library for interacting with the [Galaxy](https://galaxyproject.org/) REST API. It wraps the API in a functional programming style using [Effect-TS](https://effect.website/)—enabling type-safe error tracking, composable operations, and robust error handling for bioinformatics workflow execution.

## Key Features

- **Type-safe API**: Full TypeScript definitions for Galaxy REST API responses
- **Type-safe Error Handling**: Discriminated union errors tracked at the type level
- **Dual API Design**: Choose between `Effect.Effect` (composable) and `Promise` (convenience)
- **Retry Logic**: Automatic exponential backoff for transient failures (429/503)
- **TUS Resumable Uploads**: Upload large files with automatic resumable support
- **Layer-based DI**: Testable dependency injection using Effect `Context.Tag`
- **Comprehensive Types**: 50+ TypeScript types covering workflows, histories, datasets, tools, jobs, and invocations
