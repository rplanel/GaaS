## Configuration

Before calling any function, you need to provide Galaxy credentials. Blendtype uses Effect-TS `Layer` for dependency injection.

### Creating a Configuration Layer

```typescript [config.ts]
import { makeGalaxyLayer } from 'blendtype'

// Create the Galaxy layer with your credentials
const galaxyLayer = makeGalaxyLayer({
  url: 'https://usegalaxy.org', // Your Galaxy server URL
  apiKey: 'your-api-key-here' // Get from Galaxy user preferences
})
```

::warning
Never hardcode API keys. Use environment variables or a configuration file.
::

## Choose Your API Style

Blendtype provides every operation in two styles:

### Promise API

For quick, direct usage. The layer is provided automatically.

```typescript [Promise API]
import { createHistory } from 'blendtype'

async function main() {
  // Create a history (layer injected internally)
  const history = await createHistory('My Analysis')
  console.log(`Created history: ${history.id}`)
}

main().catch(console.error)
```

### Effect API

For composable, testable pipelines. You manually provide layers.

```typescript [Effect API]
import { createHistoryEffect } from 'blendtype'
import { Effect } from 'effect'

const program = Effect.gen(function* () {
  const history = yield* createHistoryEffect('My Analysis')
  console.log(`Created history: ${history.id}`)
  return history
})

// Execute with the layer
Effect.runPromise(Effect.provide(program, galaxyLayer))
  .then(console.log)
  .catch(console.error)
```

::tip
**When to use which?**
- **Promise**: Quick scripts, one-off operations, team members new to Effect-TS
- **Effect**: Complex pipelines, batch operations, testing, retry logic
::

## Your First Operation: Create a History

Histories are containers for datasets and analyses in Galaxy.

::code-group

```typescript [Promise]
import { createHistory } from 'blendtype'

const history = await createHistory('RNA-seq Analysis')
console.log(history.id) // Galaxy history ID
console.log(history.name) // "RNA-seq Analysis"
```

```typescript [Effect]
import { createHistoryEffect } from 'blendtype'
import { Effect } from 'effect'

const program = Effect.gen(function* () {
  const history = yield* createHistoryEffect('RNA-seq Analysis')
  return history
})

const result = await Effect.runPromise(
  Effect.provide(program, galaxyLayer)
)

console.log(result.id)
```

::

## Complete Example: Upload and Invoke

```typescript [analysis.ts]
import {
  createHistoryEffect,
  invokeWorkflowEffect,
  makeGalaxyLayer,
  uploadFileToHistoryFromUrlEffect
} from 'blendtype'
import { Effect } from 'effect'

const layer = makeGalaxyLayer({
  url: process.env.GALAXY_URL!,
  apiKey: process.env.GALAXY_API_KEY!
})

const analysis = Effect.gen(function* () {
  // 1. Create a history
  const history = yield* createHistoryEffect('Automated RNA-seq')

  // 2. Upload data
  const dataset = yield* uploadFileToHistoryFromUrlEffect({
    historyId: history.id,
    srcUrl: 'https://example.com/rnaseq.fastq',
    name: 'rnaseq.fastq'
  })

  // 3. Invoke a workflow
  const invocation = yield* invokeWorkflowEffect(
    history.id,
    'workflow-galaxy-id',
    { 0: { id: dataset.id, src: 'hda' } }, // Map input datasets
    {} // Tool parameters
  )

  return { history, dataset, invocation }
})

// Execute the full pipeline
Effect.runPromise(Effect.provide(analysis, layer))
  .then((result) => {
    console.log('Workflow started:', result.invocation.id)
  })
  .catch((error) => {
    console.error('Pipeline failed:', error)
  })
```
