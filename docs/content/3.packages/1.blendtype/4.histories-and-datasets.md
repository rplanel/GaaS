## History Operations

Histories are Galaxy containers for datasets and analyses. All operations support both Promise and Effect APIs.

### Create a History

```typescript [Promise]
import { createHistory } from 'blendtype'

const history = await createHistory('My RNA-seq Analysis')
console.log(`Created: ${history.id} (${history.name})`)
```

### Get History Details

```typescript [Promise]
import { getHistory } from 'blendtype'

const history = await getHistory('history-123')
console.log(history.state) // "ok", "queued", "running", etc.
console.log(history.size) // Total size in bytes
```

### List All Histories

```typescript [Promise]
import { getHistories } from 'blendtype'

const histories = await getHistories()
const recent = histories
  .filter(h => h.state === 'ok')
  .sort((a, b) => new Date(b.update_time).getTime() - new Date(a.update_time).getTime())
```

### Delete a History

```typescript [Promise]
import { deleteHistory } from 'blendtype'

const deleted = await deleteHistory('history-123')
console.log(`Purged: ${deleted.purged}`)
```

::warning
Deleting a history purges all datasets it contains. This cannot be undone.
::

## File Uploads

Blendtype supports two upload methods. Each handles errors gracefully by cleaning up (deleting the history) on failure.

### Upload from URL

For files accessible via HTTP(S). Uses Galaxy's `fetch` tool.

```typescript [Promise]
import { uploadFileToHistoryFromUrl } from 'blendtype'

const dataset = await uploadFileToHistoryFromUrl({
  historyId: 'history-123',
  srcUrl: 'https://example.com/data.fastq',
  name: 'sample.fastq'
})

console.log(`Uploaded: ${dataset.id} (${dataset.name})`)
```

### Upload from Buffer (TUS Resumable)

For local files or buffers. Uses [TUS protocol](https://tus.io/) for resumable uploads—ideal for large files.

```typescript [Promise]
import { Buffer } from 'node:buffer'
import { uploadFileToHistoryFromBuffer } from 'blendtype'

const buffer = Buffer.from('ATCGATCG...') // Or read from file

const dataset = await uploadFileToHistoryFromBuffer({
  historyId: 'history-123',
  buffer,
  name: 'genome.fasta'
})

console.log(`Uploaded: ${dataset.id}`)
```

::tip
**When to use which?**
- **URL upload**: When data is already on a public URL or you want Galaxy to fetch it directly
- **Buffer upload**: When data is in memory, in a local file, or when you need TUS resumable capabilities for large files
::

### TUS Configuration

The TUS upload splits files into chunks and resumes automatically on failure:

| Option | Default | Description |
|--------|---------|-------------|
| `chunkSize` | `10MB` | Size of each upload chunk |
| `retries` | `3` | Number of retry attempts |

## Dataset Operations

### Get Dataset Details

```typescript [Promise]
import { getDataset } from 'blendtype'

const dataset = await getDataset('dataset-456', 'history-123')
console.log(dataset.state) // "ok", "queued", etc.
console.log(dataset.file_size) // Size in bytes
console.log(dataset.extension) // "fastq", "bam", etc.
```

### Download Dataset

Download a dataset's content as a Blob.

```typescript [Promise]
import { Buffer } from 'node:buffer'
import { downloadDataset } from 'blendtype'

const blob = await downloadDataset('history-123', 'dataset-456')

// Convert to text
const text = await blob.text()
console.log(text.substring(0, 100))

// Or save to disk
const arrayBuffer = await blob.arrayBuffer()
await writeFile('output.bam', Buffer.from(arrayBuffer))
```

## Complete Example: Upload and Analyze

```typescript [upload-and-analyze.ts]
import {
  createHistoryEffect,
  downloadDatasetEffect,
  getDatasetEffect,
  makeGalaxyLayer,
  uploadFileToHistoryFromBufferEffect
} from 'blendtype'
import { Effect } from 'effect'

const layer = makeGalaxyLayer({ url: '...', apiKey: '...' })

const program = Effect.gen(function* () {
  // 1. Create history
  const history = yield* createHistoryEffect('Sample Analysis')
  yield* Effect.log(`History: ${history.id}`)

  // 2. Upload from buffer
  const dataset = yield* uploadFileToHistoryFromBufferEffect({
    historyId: history.id,
    buffer: myBuffer,
    name: 'sample.fastq'
  })
  yield* Effect.log(`Upload: ${dataset.id}`)

  // 3. Wait and check dataset status
  const details = yield* getDatasetEffect(dataset.id, history.id)
  yield* Effect.log(`Dataset state: ${details.state}`)

  // 4. Download results (when ready)
  if (details.state === 'ok') {
    const blob = yield* downloadDatasetEffect(history.id, dataset.id)
    yield* Effect.log(`Downloaded: ${blob.size} bytes`)
    return blob
  }

  return null
})

Effect.runPromise(Effect.provide(program, layer))
```
