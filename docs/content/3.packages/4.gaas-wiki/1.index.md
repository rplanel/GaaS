GaaS Wiki is a Nuxt layer that provides comprehensive documentation and wiki capabilities.
It is built on top of the [Nuxt Content](https://content.nuxt.com) module, allowing you to create and manage content easily.

It depends directly on [GaaS UI](/packages/gaas-ui) to provide a consistent user interface and user experience across the GaaS ecosystem.

## Supabase Integration

The Wiki layer inherits Supabase from `@gaas/ui` (which extends `nuxt-galaxy`). This means:

- **Auth state** is available in wiki pages for conditional content
- **Role-based navigation** — wiki nav items show/hide based on `useUserRole()`
- **Protected wiki sections** — can require authentication for specific content

### Layer Extension Chain

```
Your App (playground/)
  ├─ extends: ['@gaas/wiki']
  │  ├─ extends: ['@gaas/ui'] (auto)
  │  │  ├─ nuxt-galaxy (auto)
  │  │  │  ├─ @nuxtjs/supabase
  │  │  │  └─ Drizzle ORM
```

The Wiki layer does **not** directly import `nuxt-galaxy` — it inherits everything through `@gaas/ui`.

### Auth Configuration

Override Supabase redirect options for wiki pages:

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@gaas/wiki'],
  supabase: {
    redirectOptions: {
      exclude: ['/', '/wiki', '/wiki/**'] // Make wiki pages public
    }
  }
})
```

::warning
The wiki layer must not directly import `nuxt-galaxy`. All Supabase composables should be used through `@gaas/ui` abstractions.
::
