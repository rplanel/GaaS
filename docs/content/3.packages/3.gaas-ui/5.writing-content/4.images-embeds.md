## Image

### Using Markdown

Display images using standard Markdown syntax. Markdown images are simple to implement for basic image display.

::code-preview
![Example Image](https://picsum.photos/seed/gaas/800/400)

#code
```mdc
![Example Image](https://picsum.photos/seed/gaas/800/400)
```
::

::note
If [`@nuxt/image`](https://image.nuxt.com/get-started/installation) is installed in your Nuxt application, the `<NuxtImg>` component will be used instead of the native `img` tag for optimized image delivery.
::

### Using Embeds

Use embeds for more image customization. Embeds offer greater control over image attributes like size and styling.

::code-preview
![Example Image](https://picsum.photos/seed/gaas/800/400){height="150"}

#code
```mdc
:img{src="https://picsum.photos/seed/gaas/800/400" alt="Example Image" height="150"}
```
::
