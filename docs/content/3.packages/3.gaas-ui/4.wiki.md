Every app that extends `@gaas/ui` serves a wiki at `/wiki`, with a Wiki link in the navigation menu and a content search (<kbd>⌘</kbd> <kbd>K</kbd>). It is built on [Nuxt Content](https://content.nuxt.com): pages are Markdown files in your app's `content/wiki/`, and a page can cite articles by DOI, with the bibliography appended to it.

The wiki used to be a layer of its own, which extended `@gaas/ui`. An app that extended that layer now extends `@gaas/ui`, in `package.json` and in `extends`; the changelog's breaking changes name it.

## Collections

The wiki reads two collections:

- `content`, the wiki pages: `wiki/**/*.md`;
- `bibliography`, one CSL-JSON file per article: `bibliography/**/*.json`.

`@gaas/ui` declares both, but only as empty placeholders. Nuxt Content reads a layer's collections from the layer's own `content/` directory, so your app declares the same names in its own `content.config.ts`, and each replaces the layer's whole. The schemas come from `@gaas/ui`:

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { landingSchema } from '@gaas/ui/app/schemas/landing'
import { bibliographySchema, wikiPageSchema } from '@gaas/ui/app/schemas/wiki'

export default defineContentConfig({
  collections: {
    landing: defineCollection({
      source: 'index.yml',
      type: 'page',
      schema: landingSchema,
    }),
    content: defineCollection({
      type: 'page',
      source: 'wiki/**/*.md',
      schema: wikiPageSchema,
    }),
    bibliography: defineCollection({
      type: 'data',
      source: 'bibliography/**/*.json',
      schema: bibliographySchema,
    }),
  },
})
```

::warning
Keep the name `content`. The wiki pages, the navigation and the search all read that collection, so a wiki declared under another name is read by nothing, and `/wiki` stays empty without an error.
::

## Citations

Cite articles in a page with the `ref` component, giving one DOI or several separated by commas:

```md [content/wiki/my-page.md]
This system was first described in two articles :ref{dois="10.1234/first,10.1234/second"}.
```

Each citation reads its articles from the `bibliography` collection and links to them. When a page cites at least one DOI, a **Bibliography** section listing every cited article is appended to it, and to its table of contents.

## Public wiki pages

The wiki is behind the UI layer's [sign-in redirects](/packages/gaas-ui#sign-in-redirects), which leave only `/` and the sign-in pages open. To let visitors read it without signing in, add its pages to the open ones. The layer's own stay open, and the type requires `login` and `callback`, so repeat the layer's:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@gaas/ui'],
  supabase: {
    redirectOptions: {
      login: '/login',
      callback: '/confirm',
      exclude: ['/wiki', '/wiki/**'],
    },
  },
})
```
