<assumptions>
## Environment constraint

The failure is environment-specific: Vitest's default `forks` pool triggers an unclassified write error (errno -122) during worker IPC in this runtime. The `threads` pool does not exhibit the failure and is a supported, first-class Vitest execution mode. Switching pools is therefore a runner-configuration fix, not a test disable or coverage reduction.

## Scope boundary

This plan only changes Vitest `pool` settings. It does not refactor tests, disable suites, remove coverage, or alter package `test` scripts. If a package still fails after the pool change, the failure is a separate issue outside this phase's scope.

## Broken windows ledger

Marking broken window #2 fixed is part of Phase 5 (`Verify Gates and Close Broken Windows`). This plan documents the verification evidence needed for that close-out but does not itself edit `.planning/WINDOWS.md`.
</assumptions>
