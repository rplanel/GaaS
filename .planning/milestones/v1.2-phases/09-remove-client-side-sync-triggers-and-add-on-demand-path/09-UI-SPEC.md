## Visual Hierarchy

| Surface | Focal Point | Treatment |
|---------|-------------|-----------|
| `pages/analyses/[analysisId].vue` | Analysis name in `UDashboardNavbar` | Display weight (600), 28px, line-height 1.2, single-line truncate |
| Secondary action | "Sync now" `UButton` | Accent color (`--ui-primary`), placed to the right of the heading row |
| Icon-only action | Existing "Run Again" icon button | Must be wrapped in `UTooltip` or carry `aria-label="Run again"` for accessibility |

*Source: CONTEXT.md D-08 and accessibility review.*

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#fafafa` (`--ui-bg`, zinc-50 light) | App background, surfaces |
| Secondary (30%) | `#ffffff` (`--ui-bg-elevated`) | Cards, sidebar, elevated panels |
| Accent (10%) | `#4f46e5` (`--ui-primary`, indigo-600) | Primary buttons, active nav, selected list row, status emphasis |
| Destructive | `#dc2626` (`--ui-error`, red-600) | Delete actions and error alerts only |

Accent reserved for:
- Primary CTA button ("Sync now")
- Active/selected state in the analyses list (`border-primary`, `bg-primary/10`)
- Active navigation items
- Selected status emphasis (e.g. Galaxy status indicators)

*Source: `packages/ui/app/app.config.ts` sets `ui.colors.primary: 'indigo'` and `ui.colors.neutral: 'zinc'`.*

## UI Considerations

Applicable state considerations resolved: 13 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Analysis detail header (`pages/analyses/[analysisId].vue`) | covered | Falls back to "Unnamed" when `analysis.name` is missing. |
| populated | Analysis detail header | covered | Shows analysis name and `created_at` badge in `UDashboardNavbar`. |
| overflow | Analysis detail header | covered | Long analysis names truncate with `truncate` class on the title span. |
| long-text | Analysis detail header | covered | Same truncation rule prevents layout breakage. |
| loading | "Sync now" button (`pages/analyses/[analysisId].vue`) | covered | `UButton` displays a loading spinner while the `POST /api/db/analyses/:id/sync` request is in flight. |
| error | "Sync now" button | covered | On fetch failure a toast is shown with title "Sync failed" and the error-state body copy. |
| empty | Analysis history panel inputs/outputs (`GalaxyAnalysisIoDatasetsList`) | covered | Renders "No datasets available." when `sanitizedItems.length === 0`. |
| populated | Analysis history panel inputs/outputs | covered | Displays dataset count label (singular/plural) and a responsive `UPageGrid`. |
| zero-one-many | Analysis history panel inputs/outputs | covered | Count label uses `"dataset" / "datasets"` based on length. |
| loading | Analysis history panel (`AnalysisHistoryPanel.vue`) | covered | `pendingAnalysis` shows a skeleton loader (circle + two bars). |
| error | Analysis history panel | covered | `workflowError` renders a `UAlert` with `color="error"` and the error message. |
| overflow | Analysis history panel stdout/stderr | covered | `pre` blocks are wrapped in `overflow-x-auto` containers. |
| long-text | Analysis history panel stdout/stderr | covered | `pre` uses `text-nowrap`; horizontal scroll handles long lines. |
| empty | Analyses list (`AnalysisListPanel.vue`) | backstop | No explicit empty row exists today; add "No analyses yet" row and verify with a visual test. |
| populated | Analyses list | covered | Renders one row per sanitized analysis with status icon, name, and workflow badge. |
| overflow | Analyses list | covered | List container uses `overflow-y-auto`; row text truncates with `truncate`. |
| long-text | Analyses list | covered | Analysis name and workflow name rows use `truncate`. |

*Source: ui-consideration-probe taxonomy applied to the surfaces described above.*
