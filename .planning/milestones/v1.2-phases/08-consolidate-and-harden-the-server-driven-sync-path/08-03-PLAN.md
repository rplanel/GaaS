Purpose: Galaxy and Supabase can return transient 503/429 or network errors. A bounded retry with backoff reduces false failures, while sync-attempt tracking prevents immediate re-selection and supports observability.
Output: Updated syncAnalysisEffect with retry logic and sync-attempt column updates, plus tests for retry and tracking behavior.
</objective>
