<objective>
Prevent duplicate storage uploads when the analysis-level retry re-runs syncOutputDatasetEffect on an already-synced dataset, and confirm that per-analysis failure isolation remains intact.

Purpose: Without the idempotency guard, every retry of a completed analysis would re-download and re-upload output datasets, creating orphaned storage objects and wasting bandwidth. This plan short-circuits unchanged outputs and verifies the surrounding failure isolation.
Output: Updated output.ts with the idempotency guard and output tests covering skip and upload paths.
</objective>
