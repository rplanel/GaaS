# Requirements: GaaS — Galaxy as a Service

**Defined:** 2026-08-05
**Core Value:** Developers can reliably build, deploy, and operate custom Galaxy-powered web interfaces with clear observability, because structured logging makes runtime behavior understandable to both humans and LLMs.

## v1 Requirements

Requirements for the **Restore Quality Gates** milestone.

### Typecheck fixes

- [x] **TYPE-01**: `HeroShadersDynamic.vue` can dynamically import `HeroShaders.client.vue` without a module-not-found TypeScript error.
- [x] **TYPE-02**: `plot/Table.vue` `defineModel('columnVisibility')` accepts a default factory returning `Record<string, boolean>` without a type error.
- [x] **TYPE-03**: `plot/Table.vue` reads `tableElem?.tableApi` state without assigning `() => {}` to `VisibilityState`.
- [x] **TYPE-04**: `pages/index.vue` passes a valid `ClipboardValue` to `copy()` even when `page.cta.command` may be `undefined`.

### Test runner fixes

- [x] **TEST-01**: The root `pnpm test` Vitest forks-pool `Unknown system error -122 write` failure is reproduced and root-caused.
- [x] **TEST-02**: The root test runner configuration or environment issue is fixed so `pnpm test` no longer fails with the forks-pool error.

### Verification

- [x] **VERIFY-01**: Root `pnpm typecheck` passes with no errors.
- [x] **VERIFY-02**: Root `pnpm test` passes with no failures.
- [x] **VERIFY-03**: Both broken windows in `.planning/WINDOWS.md` are marked fixed after the gates pass.
