<objective>
Make the analysis create path snapshot workflow provenance onto the `analysis_monitoring` row at creation (WRIT-01).

Purpose: Every newly-persisted analysis records the workflow it ran against (`workflow_name`, `galaxy_workflow_id`, `workflow_version`) so per-workflow usage statistics survive workflow deletion (the durable survival contract from Phase 12). The single canonical insert helper `insertAnalysisMonitoringEffect` is extended to carry the snapshot, and `insertAnalysis`'s duplicated inline monitoring insert is removed so there is exactly one write path.

Output:
- `insertAnalysisMonitoringEffect` accepts a `workflowSnapshot` + optional `tx` client and writes the three snapshot columns.
- `insertAnalysis` delegates its monitoring insert to the helper inside the same `useDrizzle.transaction`.
- `analyses.post.ts` resolves the snapshot from the already-loaded `workflows` row and threads it through `runAnalysis`.
</objective>
