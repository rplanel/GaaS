Upgrade the two analysis-monitoring HTTP GET endpoints to return the full `AnalysisMonitoringStats` composite, and extract the duplicated admin-role gate into a shared generic Effect helper.

The trend granularity on the wire stays the Phase 14 default `'day'` — a `?granularity=` param is deliberately NOT added because threading it would require modifying the Phase 14 composite helpers (out-of-scope query-layer change); see discretion note in `<context>`.
